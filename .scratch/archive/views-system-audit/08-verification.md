# 08 精确分组摘要、数量与空组：实施与验证

日期：2026-09-13。状态：`implemented-awaiting-acceptance`。

前置 07 已提交为 `6c436d2b`，提交后工作区干净；本票按用户授权实施，未推送。

## 已实现

- 首屏返回有序 `groupSummary`，总数由主组摘要求和。聚合复用成员谓词、分组键和日期桶，只读取分组字段与数量；续页的摘要和总数均为 `null`，不重复聚合。未改变 cursor v3、数据库 schema 或同步 wire。
- 聚合、有效项目目录、任务页及项目名称在同一短读事务完成，避免一次响应中出现不同快照；不承诺跨分页请求冻结并发写入。COUNT-only 继续独立使用相同成员谓词。
- 后端拥有候选组与顺序：状态、优先级和日期为有限候选；主项目组按有效 scope/context 提供目录和适用独立事项；项目子组仅提供真实非空路径，没有空笛卡尔积。状态顺序统一供 SQL、游标元组和摘要排序使用。
- 前端只保留首屏摘要。每组 `totalCount` 表示完整数量，`tasks.length` 表示已加载成员；显示开关、字段显隐和折叠不进入查询身份。后续页面不覆盖首屏摘要。
- 关闭空组仅显示已加载非空组；打开后补充确认总数为零的候选组。尚未加载的非空组随分页出现，既不伪装成零，也不生成占位任务高度。无分组且零结果仍显示页面空态。
- 未完全加载的组显示“187 · 已加载 150”，菜单明确只选已加载任务。空组选择禁用，折叠与自身状态创建能力保留；可访问描述包含完整父路径和数量。唯一 renderer、viewport 与 sentinel 沿用原实现。

## 回归证据

- 新增 5 项真实 SQLite 测试：36 种主子配置对照独立摘要比较器；337 行三页且续页 SQL 不重复聚合；精确日期与空候选；scope/context、任务和项目生命周期；双连接 WAL 并发写入下的一次响应快照一致性。
- API/Query 回归先证明旧实现缺少摘要合同、丢失首屏摘要，修复后覆盖首屏必需数组、续页必需 null、查询身份与缓存保留。Display 验证后端顺序、全局数量、真实零组、未加载非空组和父子候选范围。
- 真实 Project 与 Saved 页面各使用 337 条任务三页，保留 Router、Query、生产 scene/Display/TaskBoard，仅替代 IPC 和 jsdom 几何。开关空组前后已加载 ID 和顺序不变；迟到非空组按页出现；选择只作用于已加载成员；折叠、追加、准确数量与唯一 sentinel 正确，耗尽后切换不增加请求。
- Project、所有任务、独立事项及 Saved 四类页面覆盖零结果开关、零组禁用选择、Escape 焦点恢复、重新创建 Router/QueryClient 后偏好恢复，以及关闭开关返回正确空态。
