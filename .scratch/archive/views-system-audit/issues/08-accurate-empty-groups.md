# 08: 准确显示空组与分组数量

**What to build:** 打开“显示空分组”后展示真实空组；尚未加载到的非空组不被误标为零，主/子组数量、已加载范围和任务总数保持一致。

**Blocked by:** 07 — 子分组贯通分页与层级交互。

**Status:** implemented; archived; remaining acceptance transferred

**覆盖：** V06 的空分组、AR2/AR3 的摘要与投影一致性；用户故事 36、40、47。

- [x] 复用最终成员谓词与主/子路径，在首屏提供精确分组摘要；只做有界聚合，不全量加载任务正文，续页不重复 COUNT，不另建组识别规则。
- [x] 分开表达当前组总数与已加载数；只改字段显隐、折叠或空组开关不改变任务窗口、成员数量、cursor 或摘要语义。
- [x] 状态/优先级/日期空候选为有限枚举；项目候选为当前 scope/context 的有效项目目录及适用独立事项组，project context 只含指定项目，standalone context 只含独立事项。
- [x] 关闭空组只呈现已到达且有成员的组；打开后可额外呈现确认为 0 的候选组。尚未到达的非空组仍随分页出现，不能标为 0 或预造任务高度。
- [x] 子分组只为已经呈现的父组补有限枚举空子组；项目子组只呈现实际非空路径，不生成项目目录与父组的空笛卡尔积。
- [x] 空组有稳定 key，续页按 key 合并，不重复标题、不改变已加载任务选择范围；空组折叠与组操作按实际能力工作，不伪造任务或状态。
- [x] 超过两页的真实查询夹具包含未加载非空组与真实空组；开关前后任务 ID、顺序、totalCount 均不变，摘要正确、续页不重复聚合。
- [x] 页面验证两级空组显隐、项目范围、数量文案、跨页合并、折叠/焦点、偏好默认与恢复；保持单个 sentinel、唯一 viewport 和真实已加载几何。
- [x] 核对显示面板、capability、偏好归一化与执行全部一致；更新权威文档，移除已被本票替换的空组固定关闭行为。

实施与验证见 [08 验证记录](../08-verification.md)，实际 Tauri 证据见 [09 记录](../09-verification.md)。跨设备同步未验单独记录，不新增为本包完成条件。显示面板不存在固定关闭空组的分支，保留其已有 loading 禁用规则。
