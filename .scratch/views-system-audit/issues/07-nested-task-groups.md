# 07: 子分组贯通分页与层级交互

**What to build:** 用户选择子分组后，每个主组按对应维度进一步组织任务；父子折叠、选择、跨页追加和键盘定位都与屏幕结构一致。

**Blocked by:** 06 — 主分组统一排序、折叠与选择。

**Status:** implemented-awaiting-acceptance

**覆盖：** V06 的子分组、AR2 的两级窗口、AR3 的层级投影；用户故事 37–39、47。

- [x] 同一 Display 偏好归一化、执行请求、Query key 和 cursor 增加有效子组路径，SQL 顺序为主组、子组、叶组任务；沿用 06 的组序及 05 的叶组总序。
- [x] 主分组 none 或主子同维度时子组归一为 none，面板与执行一致；仅开放现有 capability 支持的不同维度组合。
- [x] 子组 key 包含父路径，两个主组下同名子组不串折叠/选择状态；标题仅用于显示，不充当身份。
- [x] 父组折叠隐藏全部后代，子组折叠不影响兄弟；父组选择只覆盖已加载后代，子组只覆盖自己已加载成员，保持既有批量操作范围。
- [x] 层级投影进入既有 flat items、sticky、导航、焦点和 preview 恢复；一个子组跨页只出现一个逻辑组，分页追加和 sentinel 错误重试正常。
- [x] recency 在每个叶组内形成非 done/done 顺序，不跨主/子路径移动；切换子组配置废弃旧 cursor 与不适用的折叠身份。
- [x] 本票不复制摘要查询或生成空组候选，精确空组由 08 接入最终层级；保留目前空组开关状态，不声称空组已修复。
- [x] 真实查询串页结果与两级投影一致；页面使用同名子组、跨页子组和混合完成态验证父子折叠、选择、键盘/焦点、append anchor、偏好恢复。保持原有唯一 renderer 和 loaded-only 几何。
- [x] 更新已有 Display/Board 层级职责与消费者说明，移除本票替换的单层假设，不另建平行状态源。

实施与分层证据见 [07 验证记录](../07-verification.md)。实际 Tauri 验收统一在 09 执行，不以 DOM 或 SQLite 检查替代。
