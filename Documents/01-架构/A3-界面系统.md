# 界面系统

## 界面原则

- **效率优先**：高频创建、定位、推进和批量操作应短路径完成。
- **稳定优先**：Sidebar、主列表和详情层的空间关系可预测，局部操作不应无故打断扫描。
- **信息优先**：用排版、对齐、状态与轻量边界表达层级，不堆叠装饰卡片。
- **键盘优先，鼠标顺手**：快捷键和 Command 覆盖高频操作，但所有核心流程保留直接鼠标入口。
- **状态可扫读**：状态、优先级、日期与归属应比装饰更容易识别。

## 视觉系统合同

StoneFlow 页面直接使用 HeroUI OSS/Pro，不建立 `SfButton`、`shared/ui`、CVA 镜像或其他一对一视觉 wrapper。两个 renderer 只导入一次 `src/styles/index.css`；标准控件默认使用 HeroUI 上游 recipe，只叠加全局语义值与确有必要的公共差异。

视觉责任按四层 Owner 单向下沉：

| Owner | 唯一职责 |
|---|---|
| HeroUI OSS/Pro 上游 recipe | 控件结构及 Hover、Pressed、Selected、Open、Focus-visible、Disabled、Invalid、Danger、官方动效与 reduced-motion。 |
| `src/styles/theme.css` | 冷灰 Light 主题、六组 Accent、状态色、字体、边框、圆角、控件高度与阴影等全局语义值。 |
| `src/styles/components.css` | 上游无法表达的最小跨应用差异，以及经审计保留的稳定语义 hook；不复制 HeroUI 状态机。 |
| 产品 Module | Shell、PageFrame、RowShell、Detail、Board、Launcher 等稳定结构、业务语义与必要动态几何。 |

全局几何固定为：

- Control `6px`、Surface `8px`、Overlay `12px`；Button、Toggle、Chip、Avatar、ActionBar 和状态标记使用 pill，导航行本身不使用 pill；附着式 ButtonGroup 与 ToggleButtonGroup 的首、中、尾组合几何继续由 HeroUI 上游负责。
- `PageFrame` 与任务 Aside / Sheet 的内容页头共用 `PAGE_HEADER_HEIGHT = 44px`，分隔线紧接页头，避免左右工作面的边界漂移。
- 全局搜索复用 HeroUI `primary` 字段的白底，与灰色 Shell 区分；公共搜索 recipe 移除常驻阴影和外扩 ring，只保留键盘焦点的贴边提示。结果只有一个浮层，任务 / 项目使用轻分组标题与 `ListView secondary`，不再叠加分组卡片；Hover 与方向键共享唯一的 current 高亮。
- HeroUI `size='sm'/'md'/'lg'` 分别映射为 `28px/32px/36px`；强调度只由 variant 决定，不自动改变高度。
- 间距以 `4px` 为基础单位：同一紧凑语义组默认使用 `4px`，Row / Group Header 的高密度布局例外为组内 `2px`、组间 `4px`；页面 chrome、控件与边缘统一 `8px`，列表沿用 `12px` 左内边距。`12px` 及以上只表达内容组、区块或页面层级，具体间距由所属产品 Module 固定，不扩充控件内部的微型间距档。
- 高频界面图标默认不超过 `14px`；chevron、check、close 等辅助 glyph 可使用 `12px`，EmptyState、Space 预览与 AlertDialog 等强调图标可使用 `20px`。Checkbox、Radio 的 `16px` 是控件本体，不按图标缩放。
- 有明确边界的 Surface 使用 `1px` 语义边框；列表 Row 使用分隔线与状态背景；阴影只表达浮层或拖拽 elevation。

字体保持 Inter Variable 与系统中文回退。正文与标准控件以 `14px` 为基线；高频 Row 与 Sidebar 标签使用 `13px`；分组、属性与辅助信息使用 `11px/12px`，只通过字重、颜色和间距建立层级，不引入第二套字体。

Feature 与 Layout 对 HeroUI 原子控件、集合 Item 与 Overlay chrome slot，只能设置外部尺寸/位置、overflow、placement 与运行时动态几何；内部 display、gap、padding、字体、行高、图标尺寸及公共皮肤默认归 HeroUI 上游，确需跨应用统一的最小差异才进入 `components.css`。Form、RadioGroup、Toolbar、Surface、Resizable、ScrollShadow 与 Trigger 等结构组件可表达所属产品 Module 的布局，但不得拥有公共颜色、边框、圆角、阴影或交互皮肤。普通产品 wrapper 与内容子节点仍拥有自身布局和内容层级。

跨 Feature 共享只保留具有真实行为、组合合同或产品语义的深 Module。纯 class 字符串、透传 wrapper 和只有一个实现的假想 Adapter 不构成共享层；项目不保留 patterns、平行 base、旧 token/shadcn adapter、alias 或兼容出口。

## 必须统一的 UI 与交互规则

| 主题 | 规则 |
|---|---|
| 视觉基线 | 浅色、克制、高信息密度、低装饰；不做企业管理后台或消费型打卡应用风格。 |
| 页面骨架 | 主应用使用稳定 Shell；工作区集合页统一采用 Header、Toolbar、`CollectionBody` 的 `PageFrame`，列表是默认工作面，普通内容继续使用 `Body`。Default View、筛选和显示动作直接组合进 HeroUI `Toolbar`，FilterBar 位于工具条外。批量操作由 Shell 唯一的 ActionBar 承载，在 Main 的列表内容容器内底部居中，不随页面滚动，不包含 Sidebar 与详情面板的宽度；页面不另建操作条。任务正式详情在窗口 `>=1024px` 时进入 Main 内 Aside，在 `<1024px` 时进入 Sheet。 |
| 创建 | 应用外快速创建使用独立 Launcher；应用内创建使用主应用的创建弹窗。 |
| 状态操作 | 不依赖颜色作为唯一表达；文本、图标和位置共同传达状态。 |
| 危险操作 | 删除、永久删除和破坏性批量操作必须可辨识，批量破坏性操作需要二次确认。 |
| 反馈 | 保存、同步、归档、恢复与错误提供及时但克制的反馈，不打断连续操作。 |
| 布局 | 控件与列表保持稳定尺寸；窄窗口优先保证主内容和关键操作可用。 |

窗口顶栏在静态开屏、加载与恢复失败状态下保留拖动能力。主应用弹窗打开时，顶栏范围内的遮罩空白可拖动整个窗口且不关闭弹窗；弹窗自己的 Header 不承担窗口拖动。仅有普通 Dropdown / Popover 打开时，顶栏外点按住期间不将焦点推到菜单首项，也不能拖入菜单误选；松开后关闭浮层，下一次手势才拖动窗口。背景控件仍受模态隔离，非顶栏遮罩仍沿用各浮层的关闭合同，键盘焦点循环不变。

非 macOS 的自绘窗口控制使用 `36×36px`、Control 圆角的透明图标按钮，组内间距 `2px`、两侧留白 `4px`，在 `44px` 顶栏内居中、上下各留白 `4px`，不继承普通 Button 的 pill 几何。三个窗口按钮不显示 Tooltip，保留 `aria-label` 和键盘焦点。关闭键只在 Hover / Pressed 时显示危险色和反白图标，最大化后使用重叠方框表达还原；尺寸与颜色差异由 `components.css` 的窗口语义 hook 拥有，交互状态、焦点与动效继续由 HeroUI 负责。

### 共享交互状态

- HeroUI 标准控件继续使用上游 Hover、Pressed、Selected、Disabled 与 Focus-visible recipe；StoneFlow 不用组件局部 class 重写这些状态。
- 设置页的开关行直接复用 Pro `CellSwitch`，默认 Space 直接内联 Pro `CellSelect`；同步分钟与 Space 固定色板分别使用 OSS `NumberField` 与 `ColorSwatchPicker`，不保留平行 primitive 或 fallback。
- 日期选择在既有 Launcher Popover 与全局 Modal 内直接组合 OSS `Calendar`；跨 Feature 只传 `YYYY-MM-DD` 本地日历字符串，HeroUI 日期类型不得进入领域、Tauri DTO 或持久化契约。
- Alert 使用 `1px` 同色轻边界而非卡片阴影；Info/accent、Success、Warning 与 Danger 分别使用对应 soft surface，其中 Info/accent 固定表达 Info，不随用户 Accent 预设漂移。
- 指针 Hover 只改变背景，不绘制焦点边；鼠标点击不产生键盘焦点边。
- HeroUI 的 RAC `Button`、`ToggleButton` 与 `CloseButton` 统一以 React Aria 的可见焦点状态绘制 ring；鼠标关闭浮层后恢复按钮焦点但不加 ring，键盘关闭后保留 ring。修正在共享样式层完成，不在业务入口追加失焦或全局输入状态。
- 键盘 Focus-visible 使用 `--focus-ring-width: 1px` 的细边，HeroUI OSS 共同 utility、Pro 已编译 recipe 与本地焦点样式共用此宽度；既有 Row / 详情的 1px 边不再减细。校验错误 recipe 不改变，强制颜色模式保留 2px 系统 `Highlight`。
- RowShell 的 Rest 为透明，Hover 使用 `surface-hover`，Pressed 使用 `default-pressed`，Active/current 使用 `surface-active`；Selected 与 selected + hover 分别使用固定中性的 `selection` 与 `selection-hover`，不随 Accent 预设漂移。只有键盘焦点增加边界，Context Menu 打开态不伪装成键盘焦点。
- `RowShell` 是可访问交互状态壳，不拥有连续选择位置；`RowLayout` 使用 `selection`、`leading`、`primary`、`properties`、`timestamp`、`actions` 六个槽位，分为固定起始控件、弹性主内容、末端属性与操作四区。区域之间、起始控件之间及 Group Header 摘要单元之间统一 spacing `4`（16px）；末端 outline 属性之间为 spacing `2`（8px），属性组与单一时间槽之间为 spacing `4`（16px），操作区内部保持既有 2px。创建与更新时间互斥且允许都不显示，内联时间槽固定 64px、右对齐并使用等宽数字，未提供时间时不占位；显示设置和偏好归一化共用最后选择的时间项生效规则。起始控件按 `16px` 图标画布排版，点击和 Hover 同为 `16×16px`，不扩展透明热区、不绘制按钮底色，保留原生 Checkbox 选中外观和键盘焦点。Group Header 保留独立折叠语义，其折叠 / 状态分别与 Row 的勾选 / 首个图标控件对齐，标题与计数作为独立单元组成摘要区，不为任务状态列插入空占位。selection / properties（含 timestamp）/ actions 隔离 Row activation 事件；Task、Project、Lifecycle Adapter 继续拥有领域内容和动作。
- Row 属性由 Adapter 提供同一份具名内容列表，空值不产生空项；常规排版内联显示字段，紧凑排版收进 HeroUI 属性 Popover，使用原字段控件和动作，不另建业务状态。常规排版的属性入口使用 sr-only 隐藏且不占位，不随行 Hover / Focus 出现，仅入口自身获得焦点或展开时显示；紧凑排版始终可见。跨宽度编辑不卸载入口，关闭后由 HeroUI 恢复焦点，焦点离开入口后重新隐藏。没有属性时不渲染入口。只读项目及生命周期时间同样可从该入口查看，不依赖详情页兜底。
- `BoardRowSlot` 统一 section 内连续选择与 `44px` 可见 Row 壳；`BoardSectionHeader` 统一 `36px` Header anatomy。Row `44px`、Header `36px`、item gap `2px` 及其 stride 只来自共享集合几何；普通 Board 的父级布局与 TaskBoard 的虚拟几何只在相邻 item 之间放置 gap，终项不携带尾 gap，邻接、sticky、折叠与 Context Menu 仍由各 Board 决定。
- 任务的状态、优先级、项目与日期父子组共用折叠按钮、sticky 标题和组菜单。正常子组标题缩进 16px；sticky 保持一行 36px 并显示“父组 › 子组”，按钮可访问名称始终包含父路径。完整加载时菜单显示“选中全部”，部分加载时明确“选中已加载任务”，均只选择当前组的已加载成员，折叠后仍可操作；零成员组禁用选择。数量徽标显示精确总数，部分加载时追加“已加载 N”，不将未加载组误标为零；只有非空组的成员全部选中时才显示“取消选中全部”，取消保留其他组的选择，关闭菜单后焦点回到组按钮。状态图标和组内创建预填只由状态元数据提供，其他组不根据标签猜测任务属性。父组折叠隐藏全部后代，展开父组保留子组折叠；Shift 选择以叶组为边界。折叠全部后焦点回到菜单所属的可见父组。折叠偏好按来源与有效主子分组方式在本机恢复，默认全部展开。

### 创建编辑工作面

- Task / Project 共用创建容器和内容槽位，白色浮层采用创建专属 `24px` 圆角、桌面最大 `768px`；容器内边距及分区间隔为 spacing `3`（`12px`），Header 分隔符两侧与属性之间为 spacing `1.5`（`6px`）。标题、描述左侧额外缩进 `4px`，描述空态为三行 `60px`，不叠加其他分区 padding 或固定大留白。该例外由集中 recipe 的创建语义 hook 拥有，通用 Overlay 仍是 `12px`。
- 标题 `18px / 600`、描述 `14px / 400`，默认、hover 与 focus 均保持无边框、背景、阴影和 ring；透明编辑区无圆角，避免裁切贴边光标。任务标题删空不展示实时错误，但仍禁用提交并保留领域必填校验；其他校验与提交错误不隐藏，Project 名称规则不变。按钮和菜单继续使用标准焦点，强制颜色模式保留系统 Highlight。
- Header、属性与最终创建目标直接读写领域表单的同一份归属状态；显式换 Space 清除不兼容 Project，不重挂载或重置其他输入。
- 创建窗口上下各保留 `clamp(16px, 14dvh, 128px)` 安全边距，高度上限扣除上下两侧留白；描述增长后更早进入唯一 viewport 滚动，标题、属性与底栏保持可达。Task 放大填满同一可用高度且不丢输入，Project 不新增放大或日期属性。
- 仅描述 viewport 与外层 Modal 承担必要裁切，内层表单框架不裁切属性焦点边。Tab / Shift+Tab 由 React Aria 在创建会话内循环，提交后回到 Space，再依次经过 Task 的全屏、关闭、标题与描述；禁用素材及禁用创建按钮的提示包装层不进入 Tab 序，空标题时由“创建更多”直接回 Space，填写有效标题后创建按钮恢复正常停靠。共享 Tooltip 不消费键盘事件，子控件仍可明确消费自己的按键。
- 创建与其他 `ActionTooltip` / `CommandActionTooltip` 消费者只在鼠标悬停时自动显示动作提示，Tab 仅移动焦点并保留焦点环；悬停延迟、Escape、按下关闭与外部受控开关共用 HeroUI 的唯一提示状态。含独立禁用原因的 `DisabledActionTooltip` 保留键盘解释入口；Sidebar 自带及直接使用 HeroUI 的提示不属于这条动作提示合同。共享 Action / Disabled / Overflow 提示内容声明 React Aria 的 `data-react-aria-top-layer`，保证 Modal 内打开的提示不被外部内容隔离误隐藏；背景页面仍保持不可访问，不另建 Portal 或手动删除 `aria-hidden`。
- Task 的截止 / 计划 / 提醒日期未设置时只在末尾更多菜单内；设置后按该顺序显示胶囊，两种入口共享预设、自定义日历及清除能力。自定义日历叠在创建会话上，Escape 只退最上层，清除卸载胶囊后焦点回到更多。
- 创建的 Space、状态、优先级、归属、已设置日期与更多属性按钮使用 HeroUI 原生 outline；Row 末端可编辑属性使用原生 outline，只读属性由 `MetadataFieldValue` 组合透明 Chip 与集中描边，创建与更新时间保留纯文本；Detail 字段外观不变。
- 两类创建共用底栏错误 / 计数反馈，最左侧是禁用的圆形素材图标按钮，仅占位、不触发上传或提交；pending 冻结编辑并防重复提交，失败保留输入可重试。“创建更多”成功一次后清空文本、聚焦标题并复位开关。草稿保存与关闭确认不属于当前能力。

### 任务详情容器合同

- 没有 active task 时，工作区 Main 的 `PageFrame` 只渲染任务列表。
- 从列表打开正式详情时，各宽度统一写入 `?task=` 详情意图；该 URL 只表达当前任务，不编码 Aside、Sheet 或详情呈现偏好。
- 窗口宽度 `>=1024px` 时，列表点击或 `Enter` 打开 Main 内可编辑、非模态 Aside。HeroUI Pro Resizable 保证列表 `min-width: 352px`，Aside `min-width: 320px`、默认 `360px`、`max-width: 440px`；拖宽 Aside 不得压缩列表到最小宽度以下。
- 窗口宽度 `<1024px` 时，同一 active task 渲染为 Sheet。跨越断点只替换容器，复用同一任务详情状态与草稿，不清除或改写 `?task=`，也不导航到 canonical 完整页。
- Shell controller 只派生一份 `isCompact`（窗口 `<1024px`），分别驱动 Sidebar 与任务详情容器；两者保留独立 open state，Shell 只负责保证窄窗导航 Sheet 与任务 Sheet 不同时打开。
- Task / Project / Lifecycle Row 共用 `560px` CSS 容器断点，以 Row 内容盒可用宽度为准：`<560px` 时属性收纳，`>=560px` 时内联展示；不增加其他密度档位、不换行增高，也不用窗口宽度或每行 JS 测量推导列表密度。
- `Space` 只控制只读 Peek。canonical 完整页仅由 Aside/Sheet Header 等明确入口打开，不参与断点切换或响应式回退。

## 侧栏信息架构（当前）

| 区域 | 单 Space | 所有空间 |
|---|---|---|
| 主导航 | 所有任务、视图（Saved View Library）、项目总览（**无收件箱**） | 所有任务、视图（Saved View Library）（**不展示项目总览**） |
| 项目列表 | 顶部虚拟行「独立事项」+ 当前 Space 的 Project 行 | **不展示**（所有空间只管 Task） |
| 页脚 | 归档、回收站 | 归档、回收站（scope=all 聚合） |
| Scope 切换器文案 | 当前 Space 名 | **所有空间** |

- 独立事项路径：`/$scopeKey/standalone`；产品主入口仅在单 Space；数据 = 该 Space 下 `project_id IS NULL`。
- 所有空间「所有任务」与单 Space「所有任务」列表语义相同，仅 scope 不同；行内固定展示 Space 名。
- 任务 Board 是唯一一条 **扁平混合虚拟集合**（Linear 式）生产路径：可见 header/row 的 loaded-only flat geometry、相邻 item gap 与分页未结束时的 sentinel 共同决定总高度，终项不携带尾 gap，也不为尚未加载任务制造服务端 spacer；`totalCount` 只用于加载进度与 ARIA，不改变滚动条。sentinel 区分 `idle / loading / error`，失败可原位重试，exhausted 时连同占位移除，append 以 stable key 保持视口锚点。状态在行内图标展示，各层分组均保留可折叠、sticky 的统一标题、overscan 6 与 virtual row `content-visibility`；切换查询、主子分组、排序或日期基准时显示新窗口加载态，旧来源响应不能拼入新结果；同 key 后台刷新保留已有集合。分页未结束时 `aria-rowcount=-1`，结束后报告当前可导航行数，详情关闭后的焦点按 stable task id 返回原 Row。
- 在所有空间创建任务时 Space 选择器可见且必须落到具体 Space。
- 快捷键：`G I` 前往独立事项、`N I` 新建独立事项（`S` 预留给 Space 相关能力）；在 All 下不以独立事项为主路径。
- 独立事项、所有任务、Saved View 详情与项目详情共用同一 Task Workspace 和 `TaskBoard`；`/views` 根页仅是 Saved View Library，不渲染第二套任务 Board。
- Task Workspace、项目总览、归档与回收站都通过 `PageFrame.CollectionBody` 使用同一真实 viewport；各自保留任务、项目或生命周期实体 Board。
- 上述集合首次读取且无可用结果时，保留页面框架，内容区留白并标记 `aria-busy`，不渲染骨架；Saved View 定义读取也遵循此规则。同页查询、排序或日期基准切换重新读取首屏，错误、空态与分页反馈各自保留。

### 每页 Default View 合同

Default View 是页面专属、代码定义、不入库的高频查询入口。Toolbar 使用单选 Toggle Group，任何时候都必须有且只有一项选中；不再把 Default View 伪装成 `kind=system` 的 Saved View。

| 页面 | Default View 顺序 | 默认 |
|---|---|---|
| All Tasks（所有空间或单 Space） | 未完成 / 今天（含逾期）/ 即将到期 / 全部 | 未完成 |
| Standalone | 未完成 / 今天 / 全部 | 未完成 |
| Active Project | 未完成 / 今天 / 即将到期 / 已完成 / 全部 | 未完成 |
| Completed Project | 全部 / 已完成 / 未完成 | 全部 |
| Project Overview | 进行中 / 已完成 / 全部 | 进行中 |
| Archive / Trash（所有空间） | 全部 / 空间 / 项目 / 任务 | 全部 |
| Archive / Trash（单 Space） | 全部 / 项目 / 任务；禁止出现“空间” | 全部 |
| Saved View Detail | 当前 Saved View / 所属 context 任务页的 Default View | 当前 Saved View |

- 所有 Task Workspace 的“今天”均包含尚未完成的逾期任务，避免今日执行面漏掉已经需要处理的任务。
- Project 根据自身生命周期选择 Active 或 Completed 矩阵，不通过任务计数推导项目状态。
- Saved View Detail 的第一项是当前 Saved View；后续 Default View 来自其持久化 context（`all | standalone | projectId`）。选择这些 Default View 时进入所属任务页的 canonical 结果，不把 Default View 追加成 Saved View 实体。
- `/views` 根页使用 Saved View Library 工具条（搜索、新建与库管理动作），不显示任务状态 Default View。

### 列表工具条：筛选 / 显示 / 视图操作

| 槽位 | 用途 | 组件 |
|---|---|---|
| Default View | 页面高频查询的单选入口 | HeroUI Toggle Group；稳定业务 key |
| `filterAction` | 检查完整查询并编辑 Filter Draft | `PageFilterButton` → 锚定 `FilterMenu` |
| `displayAction` | 显示选项 | `DisplayOptionsButton` |
| `filterBar` | Draft 公式、恢复与保存 | `FilterBar`；仅 `draft ≠ base` 时渲染 |
| Saved View 动作 | 创建、覆盖、重命名或删除 | 库或详情的页面专属动作；不占用 Display 槽 |

产品规则（对齐 Linear 心智）：

- **FilterQuery** 决定留下谁；**Display** 只决定怎么排、如何分组和行上显示哪些字段。“已完成是否进入结果”必须由 Default/Saved/Draft 查询表达，不是 Display 偏好。
- 分组与排序对全部匹配任务生效，第一页就是所选顺序的第一窗口，继续加载保持同一顺序；同一父子路径跨页仍是一个逻辑组。主组、子组顺序固定，组内排序方向不反转组序。分组、排序及完成项偏好先从本机恢复再读取任务，不写入 Saved View；smart/manual 隐藏方向按钮。“已完成置底，最近优先”使 done 在当前叶组内排在其他任务之后，按完成时间从近到远，覆盖这些完成项的手动位置。续页游标无法继续时可“从头加载”当前查询。显示空分组只补摘要确认的零组，未到达的非空组随分页出现；子组只在已经呈现的父组下补有限枚举空组，项目子组不补目录空组合。真实空组保留稳定标题、折叠与适用创建，关闭开关后恢复原工作台空态；无分组的零任务始终使用整页空态。
- Filter Draft 写入 URL（`f`），刷新可恢复。干净 Default View 和 Saved View 不显示 FilterBar；只有用户实际改变筛选且规范化后 `draft ≠ base` 时才显示。
- FilterBar 显示当前完整 Draft 公式，不在 clean Saved View 上重复展示 base chip。“恢复当前 View”删除 Draft 并返回 base。
- FilterMenu 始终可检查固定范围、任务归属、默认视图和完整 effective filters。条件逐条编辑，修改值保留包含/排除含义和同字段其他条件；只有明确更改运算符才反转含义。打开检查或关闭不改变查询，选择即时应用且关闭不回滚。
- 只有 `all` 默认视图、无附加条件且精确 count 为 0 才说明当前上下文没有任务；其他零结果显示“当前视图无匹配任务”并提供“调整筛选”。首屏读取、首屏失败、续页失败继续独立呈现；不为判断空态额外读取任务或把未就绪 count 当 0。
- Save 写入 `scope + context + baseViewKey + effective filters`；覆盖当前或另存为 Saved View，不写入 Display。`context` 不是可从 FilterBar 删除的 chip。
- 快捷键 `F`（及 filter.* 命令）打开锚定筛选菜单，不是全页 Command 筛选器。
