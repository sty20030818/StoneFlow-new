04 / Components

HeroUI 全局状态合同

统一状态，不做 feature 私有皮肤

这组样张固定通用控件的 default、hover、pressed/open、focus-visible、disabled、invalid 与 selected 语义。产品层只组合 HeroUI 组件，不再复制 Button、Field、Menu 或 List 的皮肤。

Button

pressed/open 是灰色填充状态；键盘焦点始终使用独立的紫色 focus ring。

Field

边框负责静态控件轮廓，focus-visible 与 invalid 由独立状态信号承担。

Menu / ContextMenu

菜单只投影 Command Catalog；右键、快捷键与 ActionBar 调用同一业务命令。
