# E1 · V1 执行文档

> 最后更新：2026-04-19 · 当前版本：V1

## 文档目标

本文件用于定义 StoneFlow `V1` 的执行范围、阶段里程碑、任务拆解与发布验收标准。

说明：

- 这是执行层文档，不重复解释产品愿景、数据模型和技术选型

---

## V1 版本目标

StoneFlow `V1` 的目标不是对外发布市场版本，而是完成一个你自己可以长期真实使用的 macOS 本地任务系统。

V1 结束时，应当做到：

- StoneFlow 已形成稳定的产品骨架：`Space -> Project -> Task`
- 用户可以通过全局入口快速创建任务，并完成整理、查看、执行、删除、恢复的完整闭环
- 产品已经具备 `Inbox / Focus / Project / Trash / Drawer` 等核心模块
- 应用已经具备足够稳定的工程结构、数据结构和 UI 壳层，可作为后续版本持续迭代的基础

## V1 版本范围

### 本版本包含

- macOS 桌面端应用形态
- `Tauri + React + TypeScript + Rust` 工程骨架
- 本地数据库：`SQLite + SeaORM`
- 顶部 `Global Command Bar`
- 左侧 `Sidebar`
- 中间 `Main`
- 右侧 `Drawer Overlay`
- `Space / Project / Task / Resource / FocusView / TrashEntry` 核心模型
- `Inbox`
- `Focus`
- `Project`
- `Trash`
- Task 资源挂载与一键打开
- 关键路径的基本测试能力

### 本版本不包含

- 账号系统
- 云同步
- 团队协作
- Web 端
- 移动端
- 复杂权限系统
- 多层子任务
- 重型项目管理能力
- 复杂自动化规则
- 复杂资源预览系统

## 版本边界

### V1 的产品边界

V1 只服务于一个目标：

> 把 StoneFlow 做成一个本地优先、适合长期自用、以极速捕获和清晰执行为核心的桌面任务系统。

因此本版本不追求：

- 对外发布时的完整营销包装
- 面向大众用户的低门槛引导体系
- 为未来协作场景提前做过多抽象

### V1 的工程边界

V1 先追求：

- 架构正确
- 数据可靠
- 主链路顺畅
- UI 壳层稳定

V1 不追求：

- 一次性做完所有边缘能力
- 为尚未出现的问题提前过度设计

## 验收标准

以下标准全部满足后，V1 才能视为完成：

- [ ] 应用可以在 macOS 本地稳定启动和运行
- [ ] 前端与 Rust 数据层已经形成稳定的工程结构
- [ ] 用户可以通过应用内入口快速创建任务
- [ ] 用户可以通过系统级 Global Command 快速创建任务
- [ ] 新任务默认进入当前 Space 的 Inbox
- [ ] 用户可以在 Inbox 中补齐必选信息并归类到 Project
- [ ] 用户可以在 Project 中查看和完成任务
- [ ] 用户点击任务后可以打开右侧覆盖式 Drawer 查看和编辑详情
- [ ] Drawer 打开时不挤压 Main，并带有极轻遮罩
- [ ] Focus 页面已支持 `Focus / Upcoming / 最近添加 / 高优先级` 四个核心 tabs
- [ ] Task 支持 `pin / unpin`
- [ ] Task 支持文档链接、本地文件、本地文件夹三种资源挂载
- [ ] 删除的 Task 与 Project 会进入 Trash
- [ ] Trash 支持恢复到原位
- [ ] 项目支持一层子项目
- [ ] 关键路径已具备基本测试覆盖
- [ ] 你本人可以连续一周使用 StoneFlow 管理真实任务，而不是只做演示

## 风险与依赖

### 当前主要风险

- 范围容易继续膨胀，削弱“快”和“顺手”
- 系统级 Global Command 的基础设施如果放得过早，会拖慢主链路推进
- Global Command 的细节如果不够强，会直接削弱 StoneFlow 的核心卖点
- Inbox、Focus、Drawer 三者之间的信息密度如果处理不好，产品会变重
- 子项目、资源、聚合视图三类能力可能继续推动数据模型变化

### 当前关键依赖

- `D1` 中核心实体与关系不发生结构性反复
- `T1` 中前后端目录与 crate 边界保持稳定
- `U1` 中壳层、令牌与 Drawer 交互规范保持稳定
- `X1` 中的关键决策持续更新，避免边做边失忆

---

## 一句话执行结论

StoneFlow 的 `V1` 不是一个功能堆叠版本，而是一个围绕“全局捕获、Inbox 整理、Project 执行、Focus 聚合、Drawer 编辑”建立起来的第一版可长期自用执行系统。
