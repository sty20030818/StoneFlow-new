## 1. 目标

恢复 **shared 防火墙**：

```txt
shared/**  不得 import  @/app  @/layout  @/features  @/routes
```

把三处「业务/壳逻辑误放在 shared」的文件 **迁出**，保留 shared 内纯 UI / 纯工具；消费者改 import。  
可选：command/bulk 根 `export *` 头刀（非必须，可本刀尾或 M-2）。

## 2. 非目标

- 不拆 ShellLayout 巨石（→ M-2）  
- 不抽 list-scene（→ M-3）  
- 不改 breadcrumb **产品文案/行为**（只搬家）  
- 不强制上 eslint-plugin-boundaries（本刀可用 rg 验收；lint 规则可单列后续）  
- 不重命名全仓 `shared/ui` → `shared/components`（To-Be 命名可随 touch）

## 3. 违规点与目标落点（冻结）

| # | 现状 | 违规依赖 | 生产消费者 | **目标路径** | shared 留下 |
|---|------|----------|------------|--------------|-------------|
| A | `shared/ui/breadcrumbResolver.ts` (+test) | `app/layouts/shell/config`、`app/navigation/*`、`features/project/model/types` | inbox/all-tasks/no-project/views/project-overview/project/lifecycle/task detail 等 | **`app/navigation/breadcrumbResolver.ts`**（与 path/intent 同层）或 `app/layouts/shell/breadcrumbResolver.ts` | `AppBreadcrumb` 纯展示；`patterns/breadcrumb` class |
| B | `shared/ui/create-dialog-shell.tsx` (+test) | `features/metadata-fields` | **仅** `ShellLayout` | **`app/layouts/shell/CreateDialogShell.tsx`**（或 `shell/overlays/`） | `patterns/create-dialog` 纯 class；base Dialog |
| C | `shared/form/use-submit-target-from-form.ts` (+test) | `features/submit/model` | TaskCreate / ProjectCreate / SpaceEditor / ViewEditor | **`features/submit/model/use-submit-target-from-form.ts`**（或 `features/submit/hooks/`） | `useZodForm`、`normalize-submit-error`、form index **不再** re-export 该 hook |
