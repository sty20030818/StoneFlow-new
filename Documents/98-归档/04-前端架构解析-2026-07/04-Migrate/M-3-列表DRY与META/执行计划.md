## 1. 目标

### 1.1 SCN-D1

把 `inbox` / `all-tasks` / `no-project` 三份 **200+ 行同构编排** 收敛为：

```txt
features/task/hooks/useTaskListScene.ts   # 唯一 wiring
features/*/ui/*Page.tsx 或 routes 薄页     # variant + 少量差异 UI
```

**结束时：**

1. 列表数据 + filter + display + selection + bulk 注册 + preview 注册 **只写一处**。
2. 三页各自 ≤ ~80 行（理想）或至少 **无重复 100 行级 wiring**。
3. **禁止**把 list-scene 放进 `shared`。
4. 行为与改前一致（筛选、展示选项、多选、bulk bar、打开抽屉、预览注册、新建按钮语义）。
5. `bun run check` 绿；三页冒烟通过。

### 1.2 RING-META

`metadata-fields` **不得**依赖 `features/task/ui/*` 私有组件。

当前违规（扫描）：

| 文件 | 依赖 |
|------|------|
| `metadata-fields/core/metadata-icon-tokens.tsx` | `@/features/task/ui/PriorityIcon`、`TaskStatusIndicator` from `TaskMetadataSelect` |

**结束时：** meta 只依赖 task **model**（types/labels/options）或 **shared 纯图标**；task/ui 可依赖 meta，反向禁止。

## 4. Facade 契约（目标 API）

路径：`src/features/task/hooks/useTaskListScene.ts`（若尚无 `hooks/`，本刀创建；过渡期可先 `model/useTaskListScene.ts` 再 re-export）。

```ts
export type TaskListSceneVariant = 'inbox' | 'all' | 'no-project'

export function useTaskListScene(input: {
  variant: TaskListSceneVariant
  /** 已由页从 shellRoute 解析；facade 不读 layout context 也可，二选一要统一 */
  scope: Scope
  shellRoute: ShellRoute  // breadcrumb / spaceId
}): {
  /** EntityScene / board 需要的打包 props */
  board: { /* items, status, handlers, selection, display patch… */ }
  /** 工具条：DisplayOptions、filter pills、新建 */
  toolbar: { /* … */ }
  /** bulk bar 可见性与 snapshot */
  bulk: { selectedCount: number; /* … */ }
  meta: {
    breadcrumbItems: BreadcrumbNode[]
    displayPageKey: string
    emptyCopy?: string
  }
  /** 若页仍要自定义，可暴露底层，但默认页不该用 */
  // 避免导出 20 个底层 hook 碎片
}
```

**硬性纳入 facade（三页重复的）：**

1. `useTaskListData(listInput)`
2. `useTaskListController` 全部 mutation 透传
3. `useTaskDisplayOptions` + `applyTaskDisplayOptionsToTasks`
4. `useTaskPageFilterController` + `useRegisterPageFilterController`
5. `useTaskSelection` + `buildTaskCommandSelection` + `useRegisterCommandSelection`
6. `useRegisterTaskPreviewSource({ tasks: filteredTasks, … })` ← 修 fresh-deps 的关键点
7. projectOptions / spaces 拉取与 variant 过滤
8. `openEntityDrawer` / preview controller 接线进 board handlers

**可留在薄页：**

- `EntityScene` JSX 槽位拼装（若差异大）
- 或进一步 `TaskListSceneView` 组件吃 facade 返回值（本刀推荐 **一步到位 View 组件**，三页只传 variant）

### 4.1 推荐落地形态（更 KISS）

```txt
features/task/
  hooks/useTaskListScene.ts
  ui/TaskListSceneView.tsx   # EntityScene + BulkActionBar + 标准 toolbar
  # 可选 index 导出

features/inbox/ui/InboxPage.tsx
  → return <TaskListSceneView variant="inbox" />
```

这样 routes **不必**本刀改路径（仍挂 InboxPage），Delete 目录可延后。

## 5. RING-META 修法

### 5.1 问题

`metadata-fields/core` 引用 `task/ui` → 实现环，删/换 task UI 会扯 meta。

### 5.2 候选（选一，推荐 A）

| 方案 | 做法 | 评价 |
|------|------|------|
| **A 图标下沉 shared 或 task/model 纯呈现** | `PriorityIcon`、`TaskStatusIndicator` 中**无业务 hook** 的部分 → `shared/ui` 或 `task/model`+纯 SVG 组件；meta 只 import 那里 | 清晰单向 |
| B meta 只收 icon 组件 props，不 import task | 调用方（task ui）注入 icon | API 变大 |
| C meta 复制图标 | 违反 DRY | 不推荐 |

**执行推荐 A：**

1. 确认 `PriorityIcon` / `TaskStatusIndicator` 是否纯展示。
2. 若纯：迁到 `features/task/model/` 旁 `icons/` 或 `shared/ui/task-indicators/`（无 feature 业务）。
3. `metadata-icon-tokens` 改 import。
4. task/ui 原路径 re-export 过渡（避免大爆改）或同步改引用。
5. `rg "from '@/features/task/ui" src/features/metadata-fields` → **零**。

labels/options 继续用 `task/model/taskPriority`、`taskStatus`（**允许** meta → task/model）。
