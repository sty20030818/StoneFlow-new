## 1. 目标结论（先读这段）

| 状态种类 | 唯一真相 | 落点（To-Be） |
|----------|----------|----------------|
| 服务端 / 持久实体 | TanStack Query | `features/*/hooks`（+ `api` IO） |
| URL / 导航位置 | TanStack Router | path + validated search（T2） |
| UI 瞬态 | local / scoped Provider / 少量 Zustand | `layout` 或 feature runtime |
| 跨启动恢复 | Tauri Store | 明确 api / `app/navigation` 边界 |
| 跨窗刷新信号 | 事件 + invalidate | workspace sync · Tauri listen |

**标准写路径（实体变更）：**

```txt
components → hooks mutation
  → api.invoke
  → （可选）emitEvent(domain:*)
  → invalidate 本域 keys 和/或 workspace 子集
  → 挂载中的 useQuery 重拉
```

**硬禁：**

- components / routes / layout **直接 invoke**  
- shared 持有实体 Query 或反向依赖 features  
- Zustand / Store **镜像** Query 列表或当前 URL 作第二真相  
- 半死 store 与 URL 双轨（目标删 drawer store）

## 2. Server state · Query

### 2.1 QueryClient 默认（目标保留 As-Is 合理值）

| 项 | 目标值 | 说明 |
|----|--------|------|
| staleTime | **30s** | 桌面本地 IPC；可按域覆盖 |
| gcTime | **10min** | |
| refetchOnWindowFocus | **false** | 桌面焦点噪音大 |
| query retry | **1** | |
| mutation retry | **0** | 写失败交给 UI |

装配：`app/bootstrap` 创建 **单例** QueryClient → `QueryClientProvider` + **同一实例**注入 Router context（loader `ensureQueryData`）。

| BP | 用法 |
|----|------|
| `cache-defaults` | 上表全局默认 |
| `cache-stale-time` | 详情/列表可 feature 级覆盖；不全局 0 |
| `cache-gc-time` | 保持 10min 级 |

### 2.2 Query Key 工厂（`qk-`）

**规则（硬）：**

1. **数组** key（`qk-array-structure`）。  
2. **层级**：`[domain, …scope, …id, …filters]`（`qk-hierarchical-organization`）。  
3. 依赖变量**全部入 key**（`qk-include-dependencies`）。  
4. 可 JSON 序列化（`qk-serializable`）。  
5. 每域 **key factory** 单文件（`qk-factory-pattern`）。

**根 domain（workspace 失效集）：**

| root | feature | 典型形状 |
|------|---------|----------|
| `tasks` | task | `list(input)` · `detail(id)` · `links(id)` |
| `projects` | project | `overview` · `sidebar` · `detail` |
| `spaces` | space | `visible` |
| `lifecycle` | lifecycle | `list(mode, scope, filter)` |
| `views` | view | `list` · `taskRun` |
| `activity` | activity | `entity(request)` |

**不在默认 workspace 失效集（正确 · DATA-D6 Accept）：**

| root | 原因 |
|------|------|
| `global-search` | 搜索瞬时查询，非实体切片 |
| `display-options` | 展示偏好，非工作区实体 |
| `healthcheck` | 诊断；无消费者则删（PLAT-D3） |

**To-Be 落点：** keys 与 queryOptions 在 `features/<x>/hooks/`（可 `hooks/keys.ts` · `hooks/queries.ts`）；经 **`index.public.ts`** 导出 loader 所需 `*QueryOptions`。

### 2.3 读路径

```txt
UI / 薄页
  → useXyzQuery / useTaskListScene（hooks facade）
  → queryFn 调 api.*（仅 hooks/api 边界）
  → Tauri invoke
```

| 允许 | 禁止 |
|------|------|
| hooks 内 `useQuery` / `useSuspenseQuery` | layout 直打 `list_tasks` api |
| loader `ensureQueryData(public options)` | 组件内拼 ad-hoc queryKey 字符串 |
| `select` 做视图投影（`perf-select-transform`） | Query 结果整表拷进 Zustand |

### 2.4 写路径 · Mutation 标准（`mut-`）

```txt
1. useMutation（hooks）
2. mutationFn → api（唯一 IO）
3. onSuccess / onSettled：
   a. 定向 invalidate 本域 keys（mut-invalidate-queries）
   b. 需要跨域时：emitEvent 和/或 invalidateWorkspaceQueries({ include })
4. 错误：归一化后抛给 UI（mut-error-handling）
5. pending：用 isPending（mut-loading-states）
```

| 模式 | 何时用 |
|------|--------|
| **域内 invalidate** | 单实体 CRUD 只影响本域（如 `taskKeys.all` + `detail`） |
| **事件 + workspace sync** | 跨窗、后端推送、多域级联（archive/lifecycle） |
| **乐观更新** | 仅高频低风险交互；必须 `onMutate` rollback（`mut-optimistic-updates` · `mut-rollback-context`） |
| **禁止** | mutation 成功只改 Zustand、不 invalidate Query |

### 2.5 预取（与 T2 衔接）

| 场景 | 做法 | BP |
|------|------|-----|
| 路由详情 | loader `ensureQueryData` | `pf-ensure-query-data` · `load-ensure-query-data` |
| Link 悬停 | router `defaultPreload: 'intent'` | `pf-intent-prefetch` · `preload-intent` |
| 手动 | 少用；命令打开实体时可 ensure | `pf-manual` 精神 |

`defaultPreloadStaleTime: 0`：**保留**（T2）；与 30s query staleTime 分工——preload 总愿刷新意图，cache 仍按 stale 服务挂载观察者。

## 3. Workspace sync 与 invalidate 策略（DATA-D1）

### 3.1 现状可保留的骨架

```txt
mutation / emitEvent / Tauri stoneflow://workspace|tasks/changed / bulk
  → features/workspace useWorkspaceSync（壳 layout 装配）
  → debounce（轻 80ms / 重 500ms 量级，实现可调）
  → invalidateWorkspaceQueries({ include? exclude? })
  → 已挂载 queries 重拉
```

工具：`shared/query/invalidation.ts`（**无业务**，只认 domain 字符串）——符合 shared 防火墙。

### 3.2 目标策略（相对 DATA-D1）

| 层级 | 策略 | 取向 |
|------|------|------|
| **L0 默认** | 未知边界的跨域变更 → invalidate **workspace 六域** | **Accept 短期**（Gap 已评；无实测痛点不先优化） |
| **L1 突变可知** | mutation 已声明影响域 → **优先 `include: [...]`** 或域内 key | **Fix 渐进** |
| **L2 事件带域** | Tauri `changedDomains` → 只 invalidate 子集 | **Keep / 加强** |
| **L3 禁区** | 不把 search / display-options / healthcheck 塞进默认六域 | **Accept（正确）** |

**原则句（冻结）：**

> 正确性优先于微优化；**先保证不漏刷**。收窄必须有「谁在听、漏刷会怎样」的证据。无痛点时 **不**为 DATA-D1 单独立项大改。

### 3.3 调用方纪律

| 调用方 | 应做 |
|--------|------|
| feature mutations | 先域内 keys；跨域再 event 或 `include` |
| bulk / shell bridge | 可 `invalidateWorkspaceQueries()` 全量；或按操作域 `include` |
| workspace sync | 统一防抖；避免每个 mutation 再叠一次无防抖全量 |
| layout | **只装配** `useWorkspaceSync(scope)`，不内联 invalidate 森林 |

### 3.4 badges 双通道（DATA-D2）

| 现状 | 目标 |
|------|------|
| sidebar badges 直打 api | **改走 Query**（同 list/lifecycle keys），吃 workspace invalidate |
| 若性能不够 | 独立 lightweight query + 明确 staleTime；**仍禁止**绕过 cache 的裸列表 |

取向：**Fix**（小刀史诗）；未修前属已知双通道。

## 4. Client state 分类表

### 4.1 决策树

```txt
需要分享给书签/深链/前进后退？ → URL（path 或 validateSearch）
是服务端/DB/IPC 实体？         → Query（hooks）
跨启动要恢复且非 URL？         → Tauri Store（经 api 或 navigation store 边界）
仅同页/同壳会话 UI？           → useState / 少量 Zustand / scoped Provider
跨组件注册（命令、选择、提交）？ → Provider registry（state/actions/meta）
跨窗临时意图？                 → Tauri event / 专用 IPC（非 Query 列表）
```

### 4.2 分类表（目标）

| 类别 | 机制 | 例子 | 禁止 |
|------|------|------|------|
| **URL** | Router | scope/section、settings section、详情 path、抽屉 `?task=`/`?project=` | 再用 Zustand 镜像 open 真相 |
| **Server cache** | Query | tasks/projects/spaces… | 列表进全局 store |
| **Shell UI 瞬态** | Zustand 或 layout local | command 面板开合、create dialog、board section 折叠 | 存实体详情全文 |
| **Route 衍生缓存** | 可由 layout 写的轻 store | `useShellNavStore` 类：**只写衍生、不读作导航真相** | 反向驱动 Router |
| **注册表** | Provider + 外部 store | selection、submit、bulk、filter、danger-confirm | 把注册表当实体 cache |
| **偏好持久化** | Store / localStorage 经 api | 侧栏宽、display-options、nav restore | 裸 invoke（DATA-D5 Fix） |
| **会话 UI** | memory | sessionRouteHistory、update phase | 持久化成导航真相 |
| **QC 会话** | QC 自有 provider/reducer | quick-create session | 共享主窗 layout store |

### 4.3 应删除 / 收口

| 项 | 动作 | Gap |
|----|------|-----|
| `useDrawerStore` 半死 | **Delete**；抽屉只认 URL search | DATA-D3 |
| shell 设备偏好裸 invoke | 收口 **settings/feature api** | DATA-D5 |
| healthcheck 无消费者 | **Delete** 接线或真接 UI | PLAT-D3 |
| badges 直 api | → Query | DATA-D2 |

### 4.4 Provider 接口（Composition · 原则级）

对齐 Vercel Composition：注册类 Provider **只暴露** `{ state, actions, meta }`，内部用 useState 还是 external store **消费者不知道**（`state-context-interface` · `state-decouple-implementation`）。细则 T4。

## 5. 事件生命周期

### 5.1 前端 eventBus（进程内）

| 类型族 | 用途 |
|--------|------|
| `task:*` / `project:*` / `space:*` | 域变更通知 → workspace 等订阅 |
| `lifecycle:changed` | 归档/垃圾箱级联 |
| `workspace:restored` | 同步恢复后全量刷新信号 |

**规则：** 发射点在 **hooks mutations**（或 api 后的单一编排），不在 deep components 随意 `emitEvent`。

### 5.2 Tauri 事件

| 事件 | 用途 |
|------|------|
| `stoneflow://tasks/changed` | 跨窗/后端任务变更 |
| `stoneflow://workspace/changed` | 同步域变更（可带 domains） |
| `stoneflow://command/open` | 外部打开实体 |
| sync / update phase | 各 feature 自有 controller |

**规则：** listen 封装在 `shared/events` 或 feature `api`；**layout 只订 sync hook**，不散落 listen。

### 5.3 刷新全图

```txt
          ┌─ mutation onSuccess ─ invalidate 域 keys
写路径 ───┤
          └─ emitEvent ──┐
                         ▼
Tauri changed ──► useWorkspaceSync ──► invalidateWorkspaceQueries
                         │
                         ▼
              Query 观察者重拉 → UI
```

## 7. 多窗口：Main vs Quick Create

| | **Main** | **Quick Create** |
|--|----------|------------------|
| 路由 | `_shell/*` 等 | `/quick-create` |
| QueryClient | 本窗实例 | **独立**本窗实例（不共享 React 树） |
| 实体读 | features public hooks | QC hooks + 可复用 task **public** 规则/types |
| 铬架 | `layout/**` | **禁止**依赖 main `layout` |
| 创建成功后 | 本窗 invalidate / 事件 | IPC/事件 → 主窗 workspace 刷新 |
| 共享层级 | — | L0 model · L1 必要 hooks/api 面 · L2 shared/components；**L3 壳禁止** |

```txt
QC commit
  → QC api invoke
  → 后端/事件 stoneflow://*
  → Main useWorkspaceSync / tasks.changed
  → Main Query invalidate
```

**禁止：** QC 直接 import main ShellLayout store；主窗假设 QC 的 React state 可达。
