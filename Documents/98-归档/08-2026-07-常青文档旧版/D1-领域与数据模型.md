# D1 · 领域与数据模型

> 最后更新：2026-04-17 · 当前实现版本：V1

## 核心实体

| 实体名称 | 中文名 | 描述 | 引入版本 |
|----------|--------|------|----------|
| Space | 空间 | 顶级领域容器，用于隔离工作、学习、生活等上下文 | V1 |
| Project | 项目 | Space 下的任务容器，是任务的长期归宿 | V1 |
| Task | 任务 | 最小执行单元，承载待办事项本身 | V1 |
| Resource | 资源 | 挂载到任务上的外部资源，如文档链接、本地文件、本地文件夹 | V1 |
| FocusView | 聚合视图 | 基于规则聚合任务的视图定义，如 Focus、Upcoming、最近添加、高优先级 | V1 |
| TrashEntry | 回收项 | 已删除 Project 或 Task 的回收站记录 | V1 |

## 实体定义

### Space

Space 代表用户的一个顶级任务领域。

| 字段名 | 类型 | 必填 | 默认值 | 说明 | 版本 |
|--------|------|------|--------|------|------|
| id | uuid | 是 | auto | 唯一标识 | V1 |
| name | string | 是 | - | 空间名称，如工作、学习、生活 | V1 |
| slug | string | 是 | derived | 稳定标识，供内部引用 | V1 |
| sort_order | integer | 是 | 0 | Space Tabs 排序 | V1 |
| is_archived | boolean | 是 | false | 是否归档 | V1 |
| created_at | timestamp | 是 | now() | 创建时间 | V1 |
| updated_at | timestamp | 是 | now() | 更新时间 | V1 |

**生命周期**：

- 创建：用户创建空间，或系统初始化默认空间。
- 修改：允许修改名称和排序。
- 删除：V1 不建议直接删除，优先归档。

---

### Project

Project 是 Space 下的任务容器。

| 字段名 | 类型 | 必填 | 默认值 | 说明 | 版本 |
|--------|------|------|--------|------|------|
| id | uuid | 是 | auto | 唯一标识 | V1 |
| space_id | uuid | 是 | - | 所属 Space | V1 |
| parent_project_id | uuid | 否 | null | 父项目，支持一层子项目 | V1 |
| name | string | 是 | - | 项目名称 | V1 |
| status | string | 是 | active | 项目状态，具体枚举在后续收口 | V1 |
| note | text | 否 | null | 项目备注 | V1 |
| due_at | timestamp | 否 | null | 项目截止时间 | V1 |
| sort_order | integer | 是 | 0 | 同级项目排序 | V1 |
| deleted_at | timestamp | 否 | null | 删除时间，null 表示未删除 | V1 |
| created_at | timestamp | 是 | now() | 创建时间 | V1 |
| updated_at | timestamp | 是 | now() | 更新时间 | V1 |

**派生字段**：

- progress：由项目下任务完成情况计算得到，不单独持久化。
- task_count：项目下任务总数，不单独持久化。
- done_task_count：已完成任务数，不单独持久化。

**生命周期**：

- 创建：用户在某个 Space 下创建项目，或在项目下创建一层子项目。
- 修改：允许修改名称、状态、备注、截止时间、排序。
- 删除：删除后进入 Trash，不直接硬删除。

---

### Task

Task 是最小执行单元。

| 字段名 | 类型 | 必填 | 默认值 | 说明 | 版本 |
|--------|------|------|--------|------|------|
| id | uuid | 是 | auto | 唯一标识 | V1 |
| space_id | uuid | 是 | - | 所属 Space，便于查询与隔离 | V1 |
| project_id | uuid | 否 | null | 所属 Project。Inbox 中允许为空，离开 Inbox 前必须存在 | V1 |
| title | string | 是 | - | 任务标题 | V1 |
| status | string | 是 | todo | 任务状态，V1 仅 `todo / done` | V1 |
| priority | string | 否 | null | 优先级，离开 Inbox 前必须设置 | V1 |
| note | text | 否 | null | 任务备注 | V1 |
| tags | json | 否 | [] | 标签列表 | V1 |
| due_at | timestamp | 否 | null | 截止时间 | V1 |
| pinned | boolean | 是 | false | 是否被手动 pin 到 Focus | V1 |
| source | string | 是 | manual | 来源，如 global_capture / inbox / project | V1 |
| deleted_at | timestamp | 否 | null | 删除时间 | V1 |
| completed_at | timestamp | 否 | null | 完成时间 | V1 |
| created_at | timestamp | 是 | now() | 创建时间 | V1 |
| updated_at | timestamp | 是 | now() | 更新时间 | V1 |

**补充说明**：

- Inbox 不是 Task 的状态，而是 Task 所处的系统模块。
- 任务在 Inbox 中默认状态就是 `todo`。
- 任务离开 Inbox 的最小条件：
  - 已设置 `priority`
  - 已设置 `project_id`
  - `status = todo`

**生命周期**：

- 创建：通过全局入口、Inbox、Project 内创建任务。
- 修改：允许修改标题、优先级、备注、标签、截止时间、pin 状态等。
- 完成：`todo -> done`，记录 `completed_at`。
- 重新打开：`done -> todo`，清空或保留 `completed_at` 的策略后续确定。
- 删除：进入 Trash，不直接硬删除。

---

### Resource

Resource 代表挂载到任务上的外部资源。

| 字段名 | 类型 | 必填 | 默认值 | 说明 | 版本 |
|--------|------|------|--------|------|------|
| id | uuid | 是 | auto | 唯一标识 | V1 |
| task_id | uuid | 是 | - | 所属 Task | V1 |
| type | string | 是 | - | 类型：doc_link / local_file / local_folder | V1 |
| title | string | 是 | - | 展示名称 | V1 |
| target | string | 是 | - | 资源目标，如 URL、文件路径、文件夹路径 | V1 |
| metadata | json | 否 | {} | 附加信息，如图标、文件扩展名、来源说明 | V1 |
| sort_order | integer | 是 | 0 | 资源排序 | V1 |
| created_at | timestamp | 是 | now() | 创建时间 | V1 |
| updated_at | timestamp | 是 | now() | 更新时间 | V1 |

**生命周期**：

- 创建：用户在 Task Drawer 中添加资源。
- 修改：允许修改标题和目标。
- 删除：从任务资源列表中移除，不进入 Trash。

---

### FocusView

FocusView 代表一个聚合视图定义。

| 字段名 | 类型 | 必填 | 默认值 | 说明 | 版本 |
|--------|------|------|--------|------|------|
| id | uuid | 是 | auto | 唯一标识 | V1 |
| space_id | uuid | 是 | - | 所属 Space | V1 |
| name | string | 是 | - | 视图名称 | V1 |
| key | string | 是 | - | 内部标识，如 focus / upcoming / recent / high_priority | V1 |
| type | string | 是 | system | system 或 user_defined | V1 |
| filter_config | json | 是 | {} | 筛选规则 | V1 |
| sort_config | json | 是 | {} | 排序规则 | V1 |
| group_config | json | 是 | {} | 分组规则 | V1 |
| sort_order | integer | 是 | 0 | tab 顺序 | V1 |
| is_enabled | boolean | 是 | true | 是否启用 | V1 |
| created_at | timestamp | 是 | now() | 创建时间 | V1 |
| updated_at | timestamp | 是 | now() | 更新时间 | V1 |

**V1 默认系统视图**：

- focus
- upcoming
- recent
- high_priority

补充约束：

- 系统会在默认 `Space` 初始化时自动写入这四个视图。
- 同一 `Space` 下 `key` 必须唯一。
- `filter_config / sort_config / group_config` 使用最小可解释 canonical config，而不是纯空 JSON 占位。

**生命周期**：

- 创建：系统初始化默认视图；后续允许用户自定义扩展。
- 修改：允许调整规则、排序、分组和顺序。
- 删除：系统视图不删除，只允许禁用；用户视图后续可删除。

---

### TrashEntry

TrashEntry 代表进入回收站的对象记录。

| 字段名 | 类型 | 必填 | 默认值 | 说明 | 版本 |
|--------|------|------|--------|------|------|
| id | uuid | 是 | auto | 唯一标识 | V1 |
| space_id | uuid | 是 | - | 所属 Space | V1 |
| entity_type | string | 是 | - | project / task | V1 |
| entity_id | uuid | 是 | - | 被删除对象 id | V1 |
| entity_snapshot | json | 是 | {} | 删除时的快照，用于恢复与展示 | V1 |
| deleted_at | timestamp | 是 | now() | 删除时间 | V1 |
| deleted_from | string | 否 | null | 删除来源，如 inbox / project / sidebar | V1 |
| created_at | timestamp | 是 | now() | 创建时间 | V1 |

**生命周期**：

- 创建：删除 Project 或 Task 时创建记录。
- 恢复：恢复到原位，恢复成功后删除对应 TrashEntry。
- 清空：永久删除时移除 TrashEntry 与目标对象。

## 实体关系

```text
Space 1 ──── * Project
Project 1 ──── * Task
Project 1 ──── * Project   // 一层子项目
Task 1 ──── * Resource
Space 1 ──── * FocusView
Space 1 ──── * TrashEntry
```

关系说明：

- **Space → Project**：一个 Space 下有多个 Project。
- **Project → Project**：Project 支持一层子项目，父子关系不无限递归。
- **Project → Task**：Task 的长期归宿是 Project，但 Inbox 中允许短暂无 project_id。
- **Task → Resource**：一个 Task 可挂多个资源。
- **Space → FocusView**：每个 Space 有自己的一组聚合视图。
- **Space → TrashEntry**：回收站按 Space 隔离。

## 本地存储模型

**存储方案**：SQLite

**选择原因**：

- StoneFlow 是本地优先的桌面端任务系统。
- 数据结构已经包含多实体、多关系、过滤排序、回收站与后续可扩展视图规则。
- 相比 JSON 文件，SQLite 更适合表达关系、查询视图和后续演进。
- 相比更重的服务端数据库，SQLite 更符合单机桌面产品阶段的复杂度。

**文件结构**：

```text
~/.stoneflow/
  ├── app.db          // 主数据库
  ├── backups/        // 自动备份
  └── logs/           // 本地运行日志（可选）
```

**表级建议**：

- spaces
- projects
- tasks
- resources
- focus_views
- trash_entries

**删除策略**：

- Project / Task：默认软删除并进入 Trash。
- Resource：直接删除。

**[V2] 同步策略**：

- 待定。
- 当前版本不设计同步实现，但字段和关系尽量不阻碍未来加入同步层。
