## 0. 契约怎么用

每个关键模块回答五问：

1. **公开 API**：外模块允许 `import` 什么？  
2. **禁止**：什么绝对不能从外触达？  
3. **装配点**：layout / routes / app 哪里挂它？  
4. **真相源**：它拥有什么状态？  
5. **删除检查清单**：卸掉时改哪里？

未单列的 feature 套用 §1 通用模板 + [`05-Feature模块化.md`](./05-Feature模块化.md) 分类表。

## 1. 通用 Feature 模板

```txt
路径：features/<name>/
公开：仅 index.public.ts（及经其 re-export 的符号）
禁止：components/** · api/** · hooks 私有文件 · model 实现细节（除非 public 显式类型）
装配：视 platform/domain/scene — layout 注册 / routes 薄页 / 他 feature public
真相：model 规则；hooks 管 Query；api 管 IO
删除：
  [ ] 全局搜 features/<name> 与 public 符号
  [ ] 卸 layout 注册行（Provider / bridge slice / overlay）
  [ ] 删相关 routes 薄页
  [ ] 清 intents / sidebar / command 入口
  [ ] 清 bulk adapter 注册
  [ ] bun run check
```

## 2. 顶层横切

### 2.1 `app`（组合根）

| 项 | 内容 |
|----|------|
| **路径** | `src/app/`（bootstrap · navigation · router） |
| **公开** | `navigation/*` 具体文件（intents、shellRoute、routePaths、sessionHistory…）；`router` 实例；bootstrap 工厂 |
| **禁止** | 业务实体规则；list-scene；侧栏 DOM |
| **装配** | `main` → App → RouterProvider |
| **真相** | 无实体数据；导航 Store 仅 restore 键 |
| **删除** | 不可删（应用无法启动）。子模块可替换实现但须保留 intent/path 语义 |

**删除 navigation 子系统（几乎不做）：** 全仓 intents/path 替换 + 启动恢复重做。

### 2.2 `layout`（铬架 · To-Be；As-Is=`app/layouts`）

| 项 | 内容 |
|----|------|
| **路径** | `src/layout/**` |
| **公开** | `AppShell`、`EntityScene`、`AppLayout` 等壳入口（供 routes） |
| **禁止** | 直接 `features/*/api`；实现命令业务体；认 Task DTO 写 Query |
| **装配** | `routes/_shell` 挂载；内部注册 platform public |
| **真相** | 壳 UI 瞬态（dialog 开合、nav 衍生 store）；**非** URL/实体 |
| **删除检查** | 主窗壳不可整删。卸**一块能力**见对应 platform feature |

### 2.3 `routes`

| 项 | 内容 |
|----|------|
| **路径** | `src/routes/**` |
| **公开** | 无（框架消费 file routes）；`-helpers` 仅 routes 内 |
| **禁止** | 厚业务 UI；裸 invoke；自管 history/Store 导航 |
| **装配** | routeTree.gen |
| **真相** | URL（Router） |
| **删除叶子** | 删文件 + 确认 intents/sidebar 无死链 + shellRoute 识别 |

### 2.4 `shared`

| 项 | 内容 |
|----|------|
| **路径** | `src/shared/{components,hooks,lib}`（To-Be；As-Is 含 `ui`） |
| **公开** | 任意无业务零件/工具 |
| **禁止** | import `@/app` `@/layout` `@/features` `@/routes`；实体业务规则；list-scene |
| **装配** | 被广泛 import |
| **真相** | 无产品实体 |
| **删除** | 按符号；确认无业务误放后再删 |

## 3. Domain features

### 3.1 `task`（试点核心）

| 项 | 内容 |
|----|------|
| **路径** | `features/task/` |
| **公开（目标）** | `useTaskListScene`；detail 相关 hooks；`taskKeys` / `*QueryOptions`；types/rules；command/bulk 相关 slice 或 adapter 工厂；可选 `TaskBoard` |
| **禁止** | 外模块深 import `components/**`、`api/**`、detail 私有路径 |
| **装配** | routes 列表/详情；layout command-bridge / bulk adapters；QC 可依赖 public |
| **真相** | tasks Query；详情/列表 facade 编排 |
| **删除检查** | |
| | [ ] 三列表 + task detail routes |
| | [ ] bridge taskSlice / bulk task adapter |
| | [ ] QC 创建依赖面 |
| | [ ] metadata 若误依赖私有 ui → 先断 |
| | [ ] workspace domain `tasks` |
| | [ ] 无残余 `@/features/task/` 深路径 |

### 3.2 `project` / `space` / `lifecycle` / `view` / `activity`

| 模块 | 公开要点 | 装配 | 删除要点 |
|------|----------|------|----------|
| **project** | detail/overview queryOptions、hooks、types、bulk/command 面 | routes 详情/概览；sidebar 项目树 | 详情+overview routes；bridge/bulk |
| **space** | visible query、CRUD hooks、scope/pending-open **api 面** | ShellRouteBoundary；侧栏；settings | active scope IPC；空间 CRUD 入口 |
| **lifecycle** | archive/trash list hooks、mutations | ultra-thin routes | archive/trash routes |
| **view** | list/run hooks（定义域） | views scene / run task view | 与 scene `views` 区分 |
| **activity** | entity query | debug route；详情 timeline | debug + 详情嵌入 |

通用禁止：外模块 `api` 深路径；components 私有。

## 4. Platform features

### 4.1 `command`

| 项 | 内容 |
|----|------|
| **公开** | command ids/types、runtime hooks、菜单 UI 入口、**actions 协议类型**；**禁止**根 `export *` |
| **禁止** | 外模块依赖私有 commands 实现文件；焊死 layout 的 34 方法实现体（应在 bridge 组合） |
| **装配** | `layout/command-bridge` + ShortcutLayer + overlays/菜单 |
| **真相** | 命令定义与启用纯规则；执行靠注入 actions |
| **删除** | [ ] bridge 整段 [ ] ShortcutLayer [ ] 菜单入口 [ ] Header 命令按钮 [ ] 确认无 feature 只依赖 types |

### 4.2 `bulk-action` / `selection` / `submit` / `filter` / `danger-confirm`

| 模块 | 公开 | 装配 | 删除 |
|------|------|------|------|
| **bulk-action** | Provider、runner hooks、**adapter 类型** | ShellProviders + domain adapters | Provider；各 adapter 注册 |
| **selection** | Provider、register hooks | ShellProviders；列表页注册 | Provider；页 register |
| **submit** | Provider、register | ShellProviders；详情/表单 | Provider |
| **filter** | Provider、hooks | ShellProviders；列表 | Provider |
| **danger-confirm** | Provider、`confirm` | ShellProviders | Provider；所有 confirm 调用点 |

标杆：submit / danger / selection — **保持薄、可插拔**。

### 4.3 `workspace` / `sync` / `update` / `global-search` / `display-options` / `entity-detail` / `metadata-fields`

| 模块 | 公开要点 | 装配 | 删除 / 注意 |
|------|----------|------|-------------|
| **workspace** | `useWorkspaceSync` | ShellRouteBoundary | 卸 hook → 无跨事件刷新 |
| **sync** | status Provider/UI | Footer | Footer 区 |
| **update** | dialog/hooks | overlays | Update 入口 |
| **global-search** | 搜索 UI/hooks | Header | Header 入口 |
| **display-options** | preference hooks | 列表 facade 内 | 随列表 |
| **entity-detail** | 抽屉 search 打开 API | shell 与 task/project | URL search 契约 |
| **metadata-fields** | 字段控件 **无 task 私有 ui** | task/project/QC 表单 | RING-META：只依赖类型/规则 |

### 4.4 `healthcheck`

| 项 | 内容 |
|----|------|
| **取向** | **Delete**（零消费者）或真接 UI 后再立契约 |
| **删除** | [ ] api/query 文件 [ ] 确认无 import |

## 5. Scene / Window

### 5.1 列表 composition-shell（inbox / all-tasks / no-project）

| 项 | 内容 |
|----|------|
| **目标** | **不保留厚 feature**；逻辑在 `task` public list-scene |
| **公开** | 无（或过渡 re-export） |
| **装配** | 仅 routes 薄页 |
| **删除（目录）** | [ ] 三目录掏空/删除 [ ] routes 已改 facade [ ] 无深 import 旧 Page |

### 5.2 `archive` / `trash`

| 项 | 内容 |
|----|------|
| **公开** | 可选极薄 Page re-export lifecycle UI |
| **装配** | routes |
| **删除** | 删 route + 1 文件即可 |

### 5.3 `views` / `project-overview` / `settings`

| 模块 | 公开 | 装配 | 删除 |
|------|------|------|------|
| **views** | 页 components（若保留 feature） | routes | routes + 页 |
| **project-overview** | 页 components | routes | routes + 页 |
| **settings** | section keys、panels、last section helpers（nav 用） | routes + sidebar | settings routes；nav 设置入口；**高联动** |

### 5.4 `quick-create`（Window）

| 项 | 内容 |
|----|------|
| **公开** | 尽量 **不对 main 暴露**；若共享规则走 **task/project public**，非 QC 私有 |
| **禁止** | main `layout`、ShellProviders、主窗 stores |
| **装配** | `routes/quick-create` + Tauri 窗 |
| **真相** | QC session/domain 自有 |
| **删除** | [ ] route [ ] 窗配置/capability [ ] 全局快捷打开 QC [ ] 确认 main 无 import QC 私有 |

### 5.5 `task-drawer`（empty）

| 项 | 内容 |
|----|------|
| **取向** | **Delete 空目录**；真抽屉在 entity-detail + task detail |
