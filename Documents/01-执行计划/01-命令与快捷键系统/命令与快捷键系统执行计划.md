### 2.2 必须删除的旧层

最终删除：

- `src/app/shortcuts/`
- `src/shared/shortcuts/`
- 旧 `ShortcutId`
- 旧 `APP_SHORTCUT_BINDINGS`
- 旧 `getShortcutDisplay`
- `ShellLayout` 内快捷键 switch

删除原则：

- 不留长期 adapter；
- 不维护两套 keybinding registry；
- 不维护两套 prefix / chord 状态机；
- 不让 Shell 拥有快捷键业务分发。

### 2.3 最终运行链路

```txt
KeyboardEvent
  -> features/command/shortcuts/CommandShortcutLayer
  -> KeybindingRegistry
  -> CommandRuntime.execute(commandId)
  -> Command.run(ctx)
  -> Shell Adapter / Feature Service
```

Command Menu、按钮、右键菜单也走同一个 `CommandRuntime`。
