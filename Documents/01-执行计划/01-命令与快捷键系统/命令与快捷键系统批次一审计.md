# StoneFlow 命令与快捷键系统最终迁移审计

> 本文原为“批次一审计”。阶段 14 后，它只记录最终迁移事实，不再描述旧系统“保持不动”的过期状态。

---

## 1. 最终入口状态

### 1.1 应用内快捷键

| 旧入口 | 最终状态 | 现行事实源 |
|---|---|---|
| `src/app/shortcuts/ShortcutManager.tsx` | 已删除 | `src/features/command/shortcuts/CommandShortcutLayer.tsx` |
| `src/app/shortcuts/useShortcutManager.ts` | 已删除 | `src/features/command/shortcuts/use-command-shortcuts.ts` |
| `src/app/shortcuts/shortcutRegistry.ts` | 已删除 | `src/features/command/keybinding/default-keybindings.ts` |
| `src/app/shortcuts/shortcutDisplay.ts` | 已删除 | `src/features/command/shortcuts/shortcut-display.ts` |
| `src/shared/shortcuts/*` | 已删除 | `src/features/command/keybinding/*` |

阶段 14 后，`src/app/shortcuts` 和 `src/shared/shortcuts` 不再存在。应用内快捷键监听只允许从 `features/command` 进入。

### 1.2 Shell 入口

| 入口 | 最终状态 | 现行事实源 |
|---|---|---|
| `ShellLayout` 旧 `ShortcutId` switch | 已删除 | `CommandRuntime.execute(commandId)` |
| `ShellHeader` 手写 Command Dialog 静态动作 | 已迁移 | `CommandMenu` 读取 `CommandRegistry` |
| Header 主按钮 / 创建菜单 | 已迁移 | `new.quickTask` / `new.fullTask` / `new.project` |

Shell 只提供 adapter action，不再拥有快捷键业务分发。

### 1.3 Tauri / Helper 边界

| 入口 | 最终状态 | 边界 |
|---|---|---|
| Helper `Option+Space` | 保留 | 系统级全局快捷键，只负责 Quick Create 唤起 / toggle |
| 主应用 command open intent | 保留 | 接收 Helper 传来的打开任务 / 项目意图 |
| 主应用应用内快捷键 | 保留 | 只在前端 `CommandShortcutLayer` 内处理 |

阶段 14 不改 Helper 行为。Helper 不判断 Row 上下文，也不注册 `C / W / P / S / D / G / O / M / F` 这类应用内快捷键。

## 3. 现行事实源

| `src/features/task/shortcuts` | Row 上下文快捷键 |
| `src/shared/ui/shortcut-menu` | Dropdown 数字选择 primitive |

## 4. 阶段 14 清理结论

阶段 14 后应满足：

- 无 `src/app/shortcuts`；
- 无 `src/shared/shortcuts`；
- 无旧 `ShortcutId`；
- 无旧 `APP_SHORTCUT_BINDINGS`；
- 无旧 `getShortcutDisplay`；
- 无 `task-create.open` / `task-create.open-fullscreen` 运行时入口；
- 无 `new.taskFullscreen` 公共命令；
- 无 `V` 全局全屏创建文案；
- 无第二套应用内 chord 状态机；
- 无第二套应用内快捷键显示工具。

当前合法保留项：

- `src/features/command/shortcuts/shortcut-display.ts`：新 CommandId 到 Keybinding 的显示工具；
- `src/features/task/shortcuts`：Row shortcut scope；
- `src/shared/ui/shortcut-menu`：Dropdown 数字选择；
- Helper `Option+Space`：系统级 Quick Create 入口。
