## 与 SPEC 的实施偏差

1. **备份范围缩小**：只导出 `spaces` / `projects` / `tasks`，不备份 views、activity、sync_*、settings、WAL/SHM 三件套。
2. **交付形态**：桌面单一 `.sql` 逻辑导出，而不是整库二进制 + 远端 Turso 全量导出。依据：旧 schema/协议将硬切，人工回退只需领域实体；且可避免把 `settings` 中的 token 拷到桌面。
3. **远端导出跳过**：用户确认已自行完成同步；导出前本地 `sync_mutations` 均为 `acked`，领域表与 shadow 计数一致。
4. **同步性能四段耗时不采集**：用户明确只要备份；该项记为「未测」，不得事后当作基线为零。
5. **在线快照**：导出时应用进程仍在，使用 `sqlite3 .backup` Online Backup API 生成一致性快照后再 dump。
