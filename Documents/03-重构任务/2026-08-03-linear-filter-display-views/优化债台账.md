### 2.4 删除清单（验收时 grep）

实现结束后，活跃路径中 **不应再出现**（测试迁移夹具除外）：

- [ ] `PageFilterState` 作为列表真源（或整个类型已删）
- [ ] `priorityValues` / `statusValues` 扁平 controller 驱动 UI 主路径
- [ ] `openCommand('filter-picker'` 作为 **唯一** 加筛入口
- [ ] `serverDrivenFilters` 跳过表（或仅测试残留）
- [ ] `externalFilter` + `EMPTY_TASKS_FOR_EXTERNAL_FILTER` 占位模式
- [ ] `showCompleted` 在 filter `hasActiveFilters` 计算中
- [ ] 产品代码从 View DTO **读取** sort/group 驱动 Board 呈现
- [ ] 运行时双解析旧 `TaskViewFilters` JSON（一次性迁移后无长期分支）

## 5. 目标架构（验收心智图）

```text
┌─────────────────────────────────────────────────────────────┐
│ UI: FilterMenu / FilterBar / DisplayPanel / Save            │
└───────────────────────────┬─────────────────────────────────┘
                            │
┌───────────────────────────▼─────────────────────────────────┐
│ Scene: base + URL temp → effective；display pageKey          │
└─────────────┬─────────────────────────────┬─────────────────┘
              │                             │
   ┌──────────▼──────────┐       ┌──────────▼──────────┐
   │ filter/core         │       │ display-options     │
   │ FilterQuery 纯函数  │       │ 呈现唯一真源        │
   │ adapt → query input │       │ 不写 View.filters   │
   └──────────┬──────────┘       └──────────┬──────────┘
              │                             │
   ┌──────────▼──────────┐       ┌──────────▼──────────┐
   │ Ports: list_tasks / │       │ Ports: display store│
   │ run_view / view CRUD│       │                     │
   └─────────────────────┘       └─────────────────────┘
```

**禁止回流：**

- UI 内手写二次滤（主路径）
- View 行再存 sort/group 当呈现
- filter 与 display 互相 import 业务状态
- 「兼容旧调用」长期 API 无删除日
